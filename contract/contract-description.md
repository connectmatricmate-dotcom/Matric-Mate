Description
We are building an AI-powered EdTech app for Pakistani school students, starting with FBISE Class 9 and later expanding to Class 10 and other boards.

The product will include a responsive web app, a real native Android app, and an admin panel/CMS. The app will provide chapter-wise study material, flashcards, MCQs, timed quizzes, audio lessons, AI tutor chat, student analytics, subscriptions, and push notifications.

This is not a simple quiz app. We need someone who can build a scalable, production-ready product with clean architecture.

*MVP Scope:*

The first version should include:

* Responsive web app
* Native Android app, not a WebView wrapper
* Admin panel / CMS
* Student authentication with email and phone OTP
* Curriculum structure: Board → Medium → Class → Subject → Chapter
* Chapter summaries / notes
* Flashcards
* MCQ practice
* Timed MCQ exams
* Confidence slider for MCQ answers
* Student progress tracking
* Analytics dashboard:

  * Accuracy
  * Confidence
  * Study activity
  * Streaks
  * Chapter progress
* AI tutor chat
* AI-generated MCQs
* Audio lessons with in-app player
* Subscription system
* Pakistani payment gateway integration
* Push notifications
* Landing page
* Deployment and documentation

*Preferred Tech Stack:*

We are open to your recommendation, but our preferred stack is:

* Next.js + TypeScript for web app, backend/API, admin panel, and landing page
* React Native + Expo for native Android app
* Supabase / PostgreSQL for database and authentication
* Firebase Cloud Messaging for push notifications
* Cloudflare / CDN setup
* Bunny.net or similar for audio/video delivery
* Claude / OpenAI / similar AI API for tutor and MCQ generation
* Safepay / PayFast or similar Pakistani payment gateway

*Important Notes:*

* Android app must be native, not just a web wrapper.
* Web and mobile should share backend logic where possible.
* Admin panel must allow content review before publishing.
* AI features must include usage limits or quotas to control cost.
* Media should be served through CDN, not directly from the main server.
* Code should be maintainable and scalable.
* We prefer a phased MVP approach.

*Future Phase Features:*

These are not required in the first MVP but may be added later:

* Class 10
* More subjects
* Video lesson library
* iOS app
* Referral / commission dashboard
* Advanced AI recommendations
* Community or leaderboard features
